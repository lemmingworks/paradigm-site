# Paradigm site

The public web pages for the Paradigm apps, served by GitHub Pages.

- `index.html`: home page for Paradigm French
- `privacy.html`: privacy policy, linked from the Google Play listing
- `terms.html`: terms of service, linked from Play Console

Plain HTML and CSS, no build step. To publish, turn on Pages in the repository settings (Deploy from a branch, `main`, root folder).
